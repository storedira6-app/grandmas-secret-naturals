# Grandma's Secret Beauty

Create a modern, highly visual, and interactive mobile-first web app for a natural beauty and lifestyle platform named "Grandma's Secret" (سر الجدة).

​الاسم الرئيسي (Brand Name): سر الجدة

​العنوان الفرعي (Tagline): طبيعي 100%

​باللغات الأخرى داخل التطبيق:

​English: Grandma’s Secret – 100% Natural

​Français: Le Secret de Grand-Mère – 100% Naturel

​Español: El Secreto de la Abuela – 100% Natural

The goal is to create an addictive, beautifully styled app that hooks the user from the very first second with warm, premium visuals and smooth animations.

---

### 🚀 1. AI Creative Freedom & UX Enhancements (Feel free to innovate!)

- You are free to add any UI/UX enhancements, micro-interactions, gamification, or features that will make users love and stay on the app.

- Suggest and implement smart interactive features (e.g., a "Daily Beauty Mood Tracker", "Skin Quiz", or "Personalized Daily Beauty Routine").

- Include engaging visual micro-animations (e.g., glowing buttons, smooth tab transitions, floating ingredient cards).

---

### 🌐 2. Language & Onboarding

- Multi-language switcher in header: العربية (RTL), English (LTR), Français (LTR), Español (LTR). Auto-switch layout directions seamlessly.

- Smooth welcome/onboarding screen with vibrant high-quality natural imagery and tagline: "We are all about natural beauty!" (احنا بتوع الطبيعي).

- One-tap "Continue with Google" sign-in integrated with Supabase/Firebase Auth.

---

### 📱 3. Core App Sections (Bottom Navigation Bar)

#### 👵 Tab 1: "Grandma Noura" AI Consultant (الجدة نورة)

- Warm, interactive chat interface with "Grandma Noura" avatar.

- Quick action pills at the bottom (e.g., "Hair Loss", "Skin Radiance", "Natural Slimming").

- Clean, readable chat bubbles with step-by-step natural recipe cards embedded in responses.

#### ✨ Tab 2: "Trending Recipes" (وصفات ترند)

- Visually rich daily feed featuring 3 highlighted natural products/recipes (e.g., Morning Mask, Day Hydrator, Night Lotion).

- High-quality image cards with ingredients, prep time, and direct action buttons.

#### 🛒 Tab 3: "Store & Shop" (المتجر)

- Premium e-commerce showcase integrated with our creator store (Ko-fi.com).

- High-res product cards with "Buy via Store" CTAs.

- Top section reserved for a stylish, non-intrusive Sponsor/Ad Banner.

#### 🗺️ Tab 4: "Natural Directory" (دليل الطبيعة)

- Interactive map and directory for local herbalist shops (معشبات), organic spas, and thermal baths with ratings and contact links.

---

### 🎨 4. Aesthetic & Design System

- Color Palette: Earthy Forest Green, Warm Sand/Beige, Soft Rose Gold/Gold accents, and Clean Cream background.

- High visual density: Use rich images, rounded corners, soft glassmorphism card effects, and elegant modern typography. ممكن ؟ وتطوره علشان ينجح ويبقى ترند  انا عاوزك تساعدني  اعمل التطبيق ده
